# Manual del Trainer · Round Training Center

Este manual cubre las funcionalidades disponibles para un **Trainer**
(monitor / encargado de un centro). El Trainer ve una versión más acotada
de la web del manager, limitada a sus propios datos.

> Total: **12 documentos**. Cada título indica el número correlativo y la
> funcionalidad.

## Cómo entras

Existen 2 modos de entrar como Trainer:

1. **El Manager te impersona** — el Manager hace login y luego elige tu
   centro desde el switch lateral del logo. Ve la web "como tú".
2. **Login directo** — entras con tu email y contraseña NoofitPro y
   automáticamente la web muestra solo lo tuyo.

En ambos casos el menú lateral te muestra solo las opciones a las que
tienes acceso. La cabecera de la barra puede mostrar un aviso "Modo
trainer" cuando el Manager te está impersonando.

## URL y acceso

- Web: `https://noofit.wiemspro.com` (también `https://round.noofit.com`)
- Login: tu email + contraseña NoofitPro

## Cómo sacar las capturas

Las capturas las saca el manager con su login real impersonando a un
trainer (o con la cuenta del trainer). Indicaciones:

1. **El manager hace login** y elige un **trainer concreto** desde el
   switch lateral (clic en el logo Round arriba).
2. La web pasa a "Modo trainer" — aparece banner naranja indicándolo.
3. Navega a la pantalla referenciada y captura.
4. Guarda en `docs/pantallas/trainer/<nombre>.png`.

Es importante que las capturas se hagan **en modo trainer**, no como
manager — algunas pantallas se ven distintas.
