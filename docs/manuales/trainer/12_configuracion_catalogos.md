# Manual Trainer · 12 de 12 · Catálogos Visibles

## Cómo llegar

Menú → **⚙ Configuración** → tab **📚 Catálogos**.

> 📷 **Captura: `12_catalogos_trainer.png`** — vista de solo lectura
> de los catálogos del manager.

## Qué ves

Los catálogos del manager (doc 32 + 37) en **modo SOLO LECTURA**:

| Catálogo | Qué incluye |
|---|---|
| Cuotas | Tipos de cuota disponibles |
| Descuentos | Descuentos aplicables |
| Modificaciones | Cargos extra puntuales (matrícula…) |
| Motivos baja | Para archivar clientes |
| Razones lead perdido | Para CRM |
| Categorías cliente | Etiquetas |
| Categorías contabilidad | Si tienes acceso a contabilidad |

## Para qué te sirve

- **Saber qué cuotas** puedes ofrecer al dar alta de cliente (doc 5)
- **Saber qué descuentos** aplicar
- **Saber qué motivos** de baja existen
- **Saber qué categorías** puedes asignar a tus clientes

## Lo que NO puedes hacer

- ❌ Crear / editar / borrar entradas — solo el manager
- ❌ Activar / desactivar — solo el manager
- ❌ Reordenar — solo el manager

Si necesitas un nuevo tipo de cuota / descuento, **pide al manager**
que lo cree.

## Tips

- Si en el formulario de alta NO ves la cuota que necesitas, repasa
  este catálogo: si no está, pídela al manager (no la crees como
  modificación, eso es otra cosa).
- Los **motivos de baja** vienen marcados con un ícono que te indica
  si bloquean envíos posteriores; si no quieres que el cliente reciba
  más comunicaciones, usa el motivo correcto.
