# Manual Trainer · 3 de 12 · Listado de Mis Clientes

## Cómo llegar

Menú → **👥 Clientes**.

> 📷 **Captura: `03_clientes_trainer_listado.png`** — tabla filtrada a
> mi centro.

## Qué ves

Lista de **solo los clientes asignados a tu centro**.

| Columna | Contenido |
|---|---|
| Foto | Avatar |
| Nombre | Nombre + apellidos |
| Email / Tel | Datos contacto |
| Cuota | Tipo |
| Estado | Activo / Pausado / Archivado |
| Última asistencia | Fecha |
| Acciones | Ver perfil · Notificar |

## Filtros

- **Estado**: Activos (default) / Todos / Archivados
- **Cuota**
- **Categoría** cliente
- **Buscar** — por nombre, email, teléfono

## Acciones por fila

- **👁 Ver perfil** — abre la ficha del cliente (doc 4)
- **📩 Notificar** — push individual (doc 10)

## Acciones masivas

- Selección múltiple → notificación a varios
- Exportar CSV (filtrado actual)

## Lo que NO puedes hacer (vs Manager)

- Mover el cliente a otro trainer (lo hace el Manager)
- Borrar definitivamente al cliente
- Cambiar cuota o aplicar descuentos sin aprobación

## Tips

- Si tienes muchos clientes inactivos pero no archivados, usa el
  filtro **Última asistencia > 14 días** para verlos.
- La columna **Estado** es lo primero que mira un trainer al empezar
  el día.
