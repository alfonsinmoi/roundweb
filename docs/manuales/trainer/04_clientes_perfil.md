# Manual Trainer · 4 de 12 · Perfil del Cliente

## Cómo llegar

Clientes → click en una fila.

> 📷 **Captura: `04_cliente_perfil_trainer.png`** — ficha del cliente.

## Qué ves

Ficha del cliente con varias pestañas:

### Datos

- Nombre, apellidos, email, teléfono, fecha nacimiento, DNI
- Foto, dirección, género
- Categoría (lectura)

### Cuota

- Tipo de cuota actual
- Periodicidad
- Importe / IVA
- Forma de pago
- Descuentos aplicados

### Recibos

- Histórico de recibos del cliente
- Estado: pagado / pendiente / devuelto
- Acciones: ver PDF, reenviar, marcar pagado manualmente

### Asistencias

- Lista de las últimas N asistencias
- Filtro por rango fechas
- Total clases mes actual / mes anterior

### Notificaciones

- Histórico de pushes que ha recibido el cliente
- Estado leído / no leído

## Acciones disponibles

- ✏ Editar datos personales
- 📩 Notificar al cliente
- 📩 Reenviar último recibo PDF
- 💳 Generar link PayComet
- ⏸ Pausar (con motivo)
- 🗄 Archivar (con motivo, tras confirmación del manager)

## Lo que NO puedes hacer

- Cambiar la cuota (necesita aprobación manager)
- Aplicar descuentos
- Borrar definitivamente

## Tips

- La pestaña **Asistencias** te avisa si el cliente ha bajado
  drásticamente su frecuencia: **buen momento para una llamada**.
- Las **Notificaciones leídas / no leídas** ayudan a saber si el
  cliente revisa la app.
