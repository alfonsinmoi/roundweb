# Manual Trainer · 11 de 12 · Mi Centro y Datos de Contacto

## Cómo llegar

Menú → **⚙ Configuración** → tab **🏢 Mi centro**.

> 📷 **Captura: `11_config_centro_trainer.png`** — formulario de tu
> centro.

## Qué puedes editar

Versión recortada del editor de centros del manager (doc 31).
Editas solo **tu propio centro**:

### Datos públicos

- Nombre del centro
- Email contacto
- Teléfono
- Web
- Instagram
- Logo (subir imagen)

### Datos fiscales

- Razón social
- CIF
- Dirección, código postal, ciudad, provincia

### Pasarela de pago propia

Solo si el manager te ha activado este permiso:

- Terminal PayComet
- API Key REST + BACK
- URL retorno OK / KO
- Botón **🧪 Probar conexión**

> 📷 **Captura: `11_pasarela_trainer.png`** — formulario de
> credenciales PayComet propias.

### Email propio

Solo si el manager te ha activado:

- Tipo: Resend / SMTP / Gmail
- Credenciales
- From email + From name

## Lo que NO puedes editar

- ❌ Slug (lo creó el manager y rompe URLs)
- ❌ Trainer NoofitPro vinculado
- ❌ Cuentas Odoo
- ❌ Permisos (los gestiona el manager)
- ❌ Datos de **otros** centros del manager

## Tips

- Antes de cambiar el **CIF**, avisa al manager: cambia la
  facturación de los recibos.
- Si tu centro tiene **email propio**, las facturas salen desde tu
  remitente; si no, salen desde el del manager.
- La **pasarela propia** sirve para que cobres directamente a tu
  cuenta bancaria sin pasar por el manager.
