## Cómo sacar las capturas

Cuando un documento referencia una captura `IMAGEN: <nombre>.png`, debes
hacer la captura tú desde la web. Indicaciones:

1. Logueado como **Manager** (sin impersonar trainer).
2. Navega a la pantalla referenciada en el documento.
3. Captura **toda la pantalla** (no solo una parte) con tu herramienta
   preferida:
   - **Windows**: tecla `Impr Pant` + Paint, o `Win + Shift + S`
   - **macOS**: `Cmd + Shift + 4`
   - **Chrome DevTools**: `F12` → menú → Capture screenshot full size
4. Guarda el PNG en `docs/pantallas/manager/<nombre>.png`. El nombre debe
   coincidir con el referenciado en el documento.

Si no quieres capturas todavía, el manual sigue siendo legible — los pasos
están descritos en texto.
