# Manual Manager · 32 de 38 · Configuración — Cuotas y Descuentos

## Cómo llegar

Configuración → tab **💶 Cuotas y Descuentos**.

> 📷 **Captura: `32_cuotas_catalogo.png`** — catálogo de cuotas.

## Qué muestra

Tres sub-pestañas:

### Cuotas

Catálogo de los tipos de cuota que ofreces:

| Columna | Contenido |
|---|---|
| Nombre | "Mensual ilimitada", "Bono 10 sesiones"… |
| Tipo | Mensual / Trimestral / Bono / Día suelto |
| Importe | € |
| IVA | % |
| Periodicidad cobro | Mensual / Trimestral / Único |
| Forma de pago default | SEPA / TPV / link |
| Activa | Sí / No |

### Descuentos

| Columna | Contenido |
|---|---|
| Nombre | "Familia numerosa", "Estudiante"… |
| Tipo | % o importe fijo |
| Valor | 10% / 5€ |
| Aplicable a | Cuotas concretas o todas |
| Vigencia | Indefinido / Temporal |

### Modificaciones

Cargos extra puntuales (matrícula, evento especial, ropa…).

## Acciones

- **Crear / editar / borrar** elementos del catálogo
- **Activar / desactivar** sin borrar (conserva histórico)
- **Asignar a clientes** desde la ficha del cliente (no aquí)

## Tips

- No borres cuotas viejas que tengan recibos asociados; **desactívalas**.
- Los descuentos se pueden combinar (familia numerosa + estudiante);
  el orden y compatibilidad se configura en el detalle.
- Las **modificaciones** son útiles para cargar matrícula sólo el
  primer mes, sin meterla en la cuota base.
