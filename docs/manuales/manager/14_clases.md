# Manual Manager · 14 de 38 · Listado de clases

## Cómo llegar

Menú → **Clases**.

> 📷 **Captura: `14_clases_listado.png`** — listado con calendario.

## Qué ves

Calendario semanal con todas las clases / sesiones programadas. Cada
celda muestra:

- Nombre de la clase / actividad
- Hora de inicio
- Monitor titular
- Plazas ocupadas / total
- Color según el estado (futura, en curso, finalizada)

## Filtros

- Vista por **semana** / **día** / **mes**
- Por **trainer**
- Por **actividad**
- Por **monitor**

## Acciones rápidas

- **Click en una clase** → abre el detalle (doc 15)
- **+ Nueva clase** → crear sesión nueva
- Drag clase a otra hora → cambiar la hora (con confirmación)

## Stats

Arriba muestra:

- Total clases de la semana
- Ocupación media
- Clases vacías (sin inscritos)

## Tips

- El sistema muestra todas las clases de NoofitPro (vía `getSalas`).
- Para gestionar inscritos, click en la clase → modal con la lista.
- Las clases pasadas se marcan en gris automáticamente.
