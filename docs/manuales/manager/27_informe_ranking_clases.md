# Manual Manager · 27 de 38 · Informe — Ranking de Clases

## Cómo llegar

Informe Asistencia → **Ranking clases**.

> 📷 **Captura: `27_ranking_clases.png`** — tabla ordenable de clases.

## Qué muestra

Tabla con **todas las clases** del rango ordenadas por ocupación:

| Columna | Contenido |
|---|---|
| Clase | Nombre + horario |
| Día | L / M / X / J / V / S / D |
| Capacidad | Plazas máximas |
| Asistencias medias | Media de los últimos N días |
| % ocupación | (asistencias / capacidad) × 100 |
| Tendencia | ↗ / ↘ / → vs período anterior |

## Ordenación

- Por defecto: **% ocupación descendente** (las que más llenan arriba)
- Click en cualquier cabecera para reordenar

## Filtros

- **Trainer**
- **Desde / Hasta**
- **Día semana** — multiselección
- **Tipo de clase** (si está categorizada)

## Indicadores

- 🟢 ≥ 80% ocupación — clase exitosa
- 🟡 50–80% — saludable
- 🔴 < 50% — clase en riesgo, valorar cambio horario o monitor

## Tips

- Si una clase top siempre llena, valora **abrir un segundo turno**.
- Si una clase está siempre vacía, prueba a moverla de horario o
  cambiar al monitor antes de cancelarla.
- La columna **Tendencia** te alerta de clases que antes funcionaban
  y se están vaciando.
