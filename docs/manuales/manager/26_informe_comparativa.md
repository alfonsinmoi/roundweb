# Manual Manager · 26 de 38 · Informe — Comparativa

## Cómo llegar

Informe Asistencia → **Comparativa**.

> 📷 **Captura: `26_comparativa.png`** — tabla mes vs mes año anterior.

## Qué muestra

Tabla **mes actual vs mismo mes año anterior** (o años anteriores) con
indicadores de cambio:

| Métrica | Este mes | Mismo mes año anterior | Δ |
|---|---|---|---|
| Asistencias totales | 1.240 | 1.080 | +14,8% 🟢 |
| Clientes activos | 156 | 142 | +9,9% 🟢 |
| Altas nuevas | 12 | 18 | -33,3% 🔴 |
| Bajas | 5 | 7 | -28,6% 🟢 |
| Recibos cobrados | 5.230 € | 4.700 € | +11,3% 🟢 |
| Recibos devueltos | 2 | 5 | -60% 🟢 |

## Filtros

- **Mes a comparar** — selector
- **Años atrás** — 1 / 2 / 3 (cuantos haya)
- **Trainer**

## Indicadores

- 🟢 Verde — variación positiva
- 🔴 Rojo — variación negativa
- ⚪ Gris — sin cambios significativos (<2%)

## Tips

- Útil para revisar al cierre de mes: "¿estamos creciendo respecto al
  mismo mes el año pasado?".
- Las **altas nuevas** son el indicador más sensible: una caída fuerte
  es señal temprana de problema de captación.
- Las **bajas** comparadas año a año tienen mucho ruido si pasa algún
  evento puntual (verano, COVID, mudanza).
