# Manual Manager · 6 de 38 · Alta de cliente nuevo

## Cómo llegar

Menú → Clientes → botón **"+ Nuevo cliente"** arriba a la derecha.

> 📷 **Captura: `06_alta_form.png`** — formulario completo de alta.

## Datos a rellenar

### Obligatorios
- Nombre
- Apellidos
- Email
- Móvil

### Recomendados
- DNI / NIF
- Fecha de nacimiento
- Género
- Dirección + Localidad + CP

### Opcionales
- Alias (apodo)
- Gympass ID (si es cliente Gympass)
- Foto

## Pasos

1. Pulsa "+ Nuevo cliente".
2. Rellena el formulario.
3. **Guardar** — si todo OK, te redirige al perfil del cliente recién creado.
4. (Opcional) Subir foto desde el perfil.

## Después del alta

El cliente queda en NoofitPro como **activo**. Recibe:

- Acceso a `mynoofit` con su email + contraseña que tú definas
- Aparece en tu listado de clientes
- Se le puede asignar inmediatamente cuotas y reservas

## Anti-duplicados

Si intentas crear un cliente con un **email o DNI ya existente**, el
sistema te avisa y **NO crea duplicado**. Te ofrece abrir el perfil
existente.

## Tips

- Si el cliente viene de un lead CRM, mejor cierra el lead **desde el
  CRM** (mover a etapa "Alta") porque eso enlaza el cliente con el lead
  histórico.
- Para Gympass, rellena el campo "Gympass ID" — es lo que evita que el
  sistema lo confunda con un cliente con cuota.
