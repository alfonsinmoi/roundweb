# Manual Manager · 3 de 38 · Menú general y navegación

## Estructura del menú

El menú lateral está organizado por bloques. Algunos son **agrupadores
desplegables** (con flecha ▾/▸):

```
🏠 Dashboard
👥 Clientes
👤 CRM ▾
   ├─ Leads
   ├─ Clientes actuales
   └─ Agenda Social
📅 Clases
💶 Económico ▾
   ├─ Cuotas mensuales
   └─ Contabilidad
📊 Informe Asistencia
⚙️ Configuración
```

> 📷 **Captura: `03_menu_completo.png`** — menú lateral expandido con
> todos los grupos abiertos.

## Cómo navegar

- Click en cualquier item plano → te lleva a esa pantalla.
- Click en un agrupador (CRM, Económico) → despliega/colapsa los hijos.
- El item activo aparece resaltado en verde.
- En móvil, el menú se cierra automáticamente al elegir un item.

## Qué hay en cada grupo

| Item | Función |
|---|---|
| Dashboard | KPIs principales |
| Clientes | Gestión completa de tus clientes |
| CRM · Leads | Embudo de captación de nuevos clientes |
| CRM · Clientes actuales | Notificaciones push a clientes |
| CRM · Agenda Social | Programar publicaciones Instagram + Facebook |
| Clases | Gestionar las clases / sesiones |
| Económico · Cuotas mensuales | Cuotas pagadas y pendientes |
| Económico · Contabilidad | Facturas, banco, cuenta de resultados |
| Informe Asistencia | Análisis de uso del centro |
| Configuración | Ajustes globales del manager |

## Header (parte superior)

- Tu nombre y centro están arriba.
- Si **estás impersonando** un trainer, aparece banner naranja
  *"Modo trainer"* en la cabecera.

## Banner clientes esperando cobro

Si tienes clientes con cuotas vencidas, sale un banner naranja arriba con
el contador. Click → te lleva al módulo Económico → Cuotas mensuales con
filtro pre-aplicado.
